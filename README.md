# Wonder Curling Simulator
文化祭にて披露したカーリングゲーム用のprocessingコード

ArduinoとJoy-Conを用いて遊ぶカーリングシミュレーションゲーム

## 説明
- 各々マイカラーをRGBで設定し、ゲームスタート
- お邪魔ストーンをどかしながら的の真ん中を目指せ
- 発射位置、発射角度を決定し、最後にパワーをためてストーン発射
- ストーンは三つまで打てる
- 真ん中から5点、3点、2点、1点でポイントが付く

## 技術的概要
- Arduinoに接続したレーザセンサによって計測した実際のストーンの速度をゲーム内のストーンの速度に変換
- Joy-Conを一本ずつ使用した二人対戦を実現
- 的の中心に近いほど得点が加算
- 隠し要素も実装

## フォルダ内
- WonderCurling/：ゲーム本体のソースコード
- Curling_PC_Only/：パソコンのみで遊べるバージョンのソースコード
- tests/：開発時に使用したテスト用ソースコード群

## 環境
- processing 3
- 主なライブラリ：GameControlPlus, Minim, Serial

## 操作方法(パソコン版)
- プレイヤー1
  - 決定・発射(長押し)　Q
  - 上　W
  - 下・キャンセル　S
  - 左　A
  - 右　D
- プレイヤー2
  - 決定・発射(長押し)　\
  - 上　↑
  - 下・キャンセル　↓
  - 左　←
  - 右　→
